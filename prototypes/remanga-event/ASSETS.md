# Арт-слоты прототипа

Каждая картинка в прототипе рендерится через `art(slotId)` (см. `js/assets.js`).
Пока у слота нет файла — рисуется SVG-заглушка.

**Как подменить заглушку реальным артом:**
1. Положите изображение в папку `assets/`, например `assets/cover_s1.webp`.
2. В `js/assets.js` в манифесте `ART` укажите имя файла:
   `'cover.s1': { src: 'cover_s1.webp', ... }`.
3. Обновите страницу — заглушка заменится на изображение.

Следующий шаг: по каждому слоту готовится промт для генерации, изображения
генерируются и кладутся в `assets/` (единый стиль отрисовки, возраст героини,
палитра и детализация фиксируются заранее — см. раздел 21 ТЗ).

## Героиня (параметрический спрайт)

Сейчас героиня рисуется кодом (`heroineSVG(cfg, emo)`) — конструктор
комбинирует слои. При переходе на генерацию нужны изображения по сетке:

- **Типажи (3):** европейский, азиатский, афро — `eu | asia | afro`
- **Цвета волос (3):** чёрные, блонд, рыжие — `black | blond | red`
- **Причёски (3):** распущенные, хвост, праздничная укладка — `loose | ponytail | festive`
- **Эмоции (7):** `calm, smile, joy, sad, angry, shy, surprised`
- **Облики (3):** простое платье (`base`), праздничное (`festive`), «Лунное платье» (`advent`)

Рекомендуемый формат файлов: `hero_{type}_{hair}_{style}_{outfit}_{emo}.png`
(PNG с прозрачностью, рост ~1000 px). Важно: одно и то же лицо во всех
вариантах — пользователь должен видеть «свою» героиню.
